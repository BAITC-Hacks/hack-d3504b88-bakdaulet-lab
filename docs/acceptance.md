После объединения выполнены `npm ci`, `npm test` (148 тестов), `npm run lint`, `npm run typecheck`, `npm run build` с изолированной demo-БД, `npm run live:check`, `npm run smoke:live`, `npm run browser:live` и `node scripts/check-ocr-live.mjs --browser` с отдельной demo-БД. Live HTTP/browser-команды требуют запущенного сервера на `http://localhost:3000`; браузерная проверка использует установленный Microsoft Edge. Скриншоты live-прохода: `screenshot-live-desktop.png` и `screenshot-live-mobile.png`. Ранее также выполнялись `npm run catalog:sync` и `npm run analogs:discover`; индекс из 500 карточек неполный.

Остатки и цены могут измениться. Перед демонстрацией перечитайте карточки или запустите проверочные команды заново. Индекс из 500 товаров неполный; отсутствие кандидата в нём не доказывает отсутствие товара в магазине. Корзина приложения собственная: заказ, резерв и запись товаров на ekt.kz не выполняются.
