Проверки выполняются командами `npm run typecheck`, `npm run lint`, `npm run test`, `npm run build`, `node scripts/smoke-http.mjs`, `node scripts/check-browser.mjs` после запуска сервера. Браузерный сценарий проверяет desktop и 390 px mobile, предложения, корзину и историю чата после перезагрузки. Скриншоты находятся в этом каталоге.

До финальной live-проверки нужно заполнить локальный `.env`, переключить `DATA_MODE=live`, запустить `npm run live:check`, синхронизировать каталог, проверить свежие детали одного доступного и одного отсутствующего товара, найти настоящую пару аналога и повторить полный сценарий. Если доступных данных не хватит для M2 или сертификата, не заменять их синтетикой под видом live.
