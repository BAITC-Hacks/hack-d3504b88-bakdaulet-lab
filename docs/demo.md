# Сценарий демонстрации

1. Запустите `npm run catalog:sync` и `npm run dev`. Проверьте режим и число товаров в `/api/health`.
2. В demo найдите `DEMO-AV16`; покажите карточку, параметры, остаток и отметку «Демонстрационные данные». В live заранее выберите актуальный товар и обновите detail.
3. Найдите `DEMO-AV16-OLD`: он без остатка, а `DEMO-AV16` является проверенным кандидатом с теми же критичными параметрами в синтетической выборке. В live сначала найдите и проверьте реальную пару; исторические остатки из мастер-плана могут измениться.
4. Спросите «Условия доставки в Алматы»; ответ должен ссылаться на официальную страницу EKT.
5. Подготовьте 1–2 шт. `DEMO-AV16`, покажите пустую корзину до подтверждения, затем подтвердите и откройте `/cart`. Обновите страницу.
6. Попросите больше 10 шт. или добавление поверх уже сохранённого остатка: сервер должен отказать.
7. Загрузите короткую XLSX-спецификацию с `DEMO-AV16` и количеством. Исправьте черновик, подготовьте предложение и отдельно подтвердите его.

На защите прямо сообщите: каталог в live читается из API партнёра; корзина прототипа собственная, так как API корзины не выдан. Синтетические примеры не являются актуальными сведениями ekt.kz.
