# Сценарий демонстрации

## Live: фактическая проверка 23.09.2026

1. В локальном `.env` задайте EKT/OpenAI-секреты, `OPENAI_MODEL=gpt-6-sol`, `DATA_MODE=live`. Запустите `npm run catalog:sync`, затем `npm run dev`. Проверьте `/api/health`: режим `live`, число проиндексированных товаров и готовность.
2. В чате введите `310100086_`. Карточка EKT `18157` показала нулевой остаток. Под ней найден кандидат `515262` (`200300265_`): при проверке было 74 шт. Совпали 3 полюса, 20 А, 400 В, 4,5 кА, характеристика C. Покажите предупреждение о непроверенной монтажной совместимости и ссылки на обе карточки EKT.
3. Спросите «Условия доставки в Алматы». Ответ должен содержать ссылку на [официальную страницу EKT](https://ekt.kz/about/information/).
4. Нажмите «Предложить 1 шт.» у аналога. Откройте `/cart` до подтверждения: корзина пуста. Вернитесь в чат, подтвердите предложение и откройте корзину; после обновления страницы позиция остаётся.
5. Повторный запрос подтверждения не дублирует количество. Запрос сверх актуального остатка отклоняется сервером. Для автоматической проверки используйте `npm run smoke:live` и `npm run browser:live`.
6. При необходимости покажите расхождение у `515291`: название говорит 160 А, свойство API — 250 А. Такая карточка не считается подтверждённой заменой.

Перед защитой запустите `npm run live:check` и `npm run analogs:discover`: цены, остатки и даже выбранная пара могут измениться. Частичный индекс не описывает весь ассортимент. Скриншоты предыдущего live-прохода находятся в `screenshot-live-desktop.png` и `screenshot-live-mobile.png`.

## Demo без внешних ключей

При `DATA_MODE=demo` используйте `DEMO-AV16-OLD` → `DEMO-AV16`. После предложения и подтверждения проверьте `/cart`. Синтетические цены и остатки не относятся к магазину. Демо-проверки: `node scripts/smoke-http.mjs` и `node scripts/check-browser.mjs`.

На защите прямо сообщите: каталог в live читается из API партнёра; корзина прототипа собственная, так как API корзины не выдан. Приложение не резервирует товар и не оформляет заказ на ekt.kz.
