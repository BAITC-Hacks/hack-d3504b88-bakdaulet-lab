Три настоящих OpenAI OCR-вызова на **синтетических** JPEG/PDF были выполнены ранее в ветке OCR и описаны в [отчёте OCR](ocr.md). Координатор не повторял платные OCR-вызовы. Фото клиента и защищённый PDF через реальный API не проверены.

В ограниченной проверке [ветки сертификатов](certificates.md) 23 реальные карточки EKT не дали подтверждённой ссылки на сертификат конкретного товара. Публичный каталог сертификатов не доказывает применимость документа к проверенной позиции.

Docker Engine на этой машине по-прежнему недоступен. Конфигурация и локальный build Next проверены, но Docker image build, Linux runtime, HTTP healthcheck и сохранность корзины после рестарта **не проверены**. Стартовый период healthcheck увеличен до 10 минут после статического анализа длительности live-синхронизации; эту настройку также нужно проверить с Engine. Не применять `down -v` к существующему тому.

Основной `.env` не включён в Git; основная SQLite не переключалась в demo. Скриншоты и JSON-артефакты не содержат ключей доступа. Остатки и цены являются наблюдением на дату проверки и должны перечитываться перед показом.
